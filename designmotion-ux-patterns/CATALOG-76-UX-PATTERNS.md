# DesignMotionHQ — Catalogue of 76 UX Patterns

English-language technical reference for interface reviews, product design, and coding agents. Each entry is an original summary rather than a verbatim transcript; consult the linked source for its full wording, examples, and updates.

## How to use

1. Identify the interface behavior and the user risk involved.
2. Open the relevant pattern and review **Key insights** and **Do / Don't**.
3. Treat measurements and timings as starting points, not universal rules.
4. Check accessibility, responsiveness, persistence, error states, and recovery.
5. Record evidence through a screenshot, test, or acceptance criterion before marking work complete.
