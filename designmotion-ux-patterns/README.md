# DesignMotion UX Patterns

An English-language UX pattern reference and skill pack covering 76 interface patterns. Each pattern file provides original technical summaries, **Key insights**, **Do / Don’t**, a verification checklist, and a link to the official source. These are not verbatim copies of third-party pages.

- Catalogue: `CATALOG-76-UX-PATTERNS.md`

- Domain skills: `skills/`
