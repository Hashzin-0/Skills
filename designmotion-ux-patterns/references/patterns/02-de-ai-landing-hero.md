## Key insights

- A generic gradient headline often hides the absence of a concrete product promise.
- State the outcome in the headline and the audience in the subtitle.
- Prefer a neutral canvas, product UI as evidence, one primary action and proof tied to a real person/result.

## Do / Don't

### Do
- Name the outcome and audience
- annotate a real product screenshot
- use verifiable customer proof with role and measurable result.

### Don't
- Fill the hero with adjectives
- put two equal CTAs side by side
- use decorative purple blobs, generic icon cards or unverifiable social proof.

## Verification checklist

- [ ] The default state and all relevant alternate states are defined.
- [ ] Mouse, keyboard, and touch interactions have been considered where applicable.
- [ ] The interface communicates what happened and what the user can do next.
- [ ] Errors and reversible actions have a predictable recovery path.
- [ ] The implementation has been tested on mobile and desktop viewports.
- [ ] The recommendation has been adapted to context rather than applied blindly.
