# 32. Proximity Rule

- **Source category:** `visual-design`
- **Official source:** [https://designmotionhq.com/patterns/proximity-rule](https://designmotionhq.com/patterns/proximity-rule)
- **Related skill:** `visual-design-systems`

> This document is an original technical summary of the linked public page, not a verbatim reproduction. Treat specific numbers and examples as source-informed heuristics and validate them against the product context, accessibility requirements, real data, and user testing.

## Key insights

- Spatial distance communicates relationship: related controls should sit closer together than separate groups.
- Spacing can establish structure without borders or cards.
- Uniform gaps flatten hierarchy and force extra visual parsing.

## Do / Don't

### Do
- Use tight intra-group spacing and larger inter-group spacing
- align related labels and controls
- test grouping at a glance.

### Don't
- Give every item equal spacing
- add borders around every group by default
- separate labels from the controls they describe.
