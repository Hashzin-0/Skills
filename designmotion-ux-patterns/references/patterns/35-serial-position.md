# 35. Serial Position

> This document is an original technical summary of the linked public page, not a verbatim reproduction. Treat specific numbers and examples as source-informed heuristics and validate them against the product context, accessibility requirements, real data, and user testing.

## Key insights

- Recall tends to favor first and last positions, while middle items are less salient.
- Use the beginning and end of sequences for high-value content, primary navigation or calls to action, without hiding essential information in the middle.

## Do / Don't

### Do
- Put the most important entry point first and a meaningful next action last
- use grouping to aid scanning.

### Don't
- Assume all list positions are equally memorable
- bury the main CTA in the middle of a long sequence.
