## Key insights

- Gestalt principles such as closure, similarity and continuity explain how people group and follow visual elements.
- Repeated visual attributes create groups
- alignment creates a reading path
- incomplete shapes can still be perceived as whole.
- Use these principles to reduce needless borders.

## Do / Don't

### Do
- Group by shared attributes
- align related content
- use consistent patterns and deliberate exceptions.

### Don't
- Scatter related elements
- use inconsistent styles for one group
- add decorative borders instead of fixing spatial relationships.
