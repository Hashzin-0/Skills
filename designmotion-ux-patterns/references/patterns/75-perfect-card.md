## Key insights

- Perceived polish can change substantially through generous padding, deliberate type hierarchy and layered shadows.
- A card needs breathing room and a clear title/body relationship
- these values should remain coherent with the overall system rather than copying one aesthetic blindly.

## Do / Don't

### Do
- Give content sufficient padding
- establish title/body contrast
- use a restrained, layered elevation style.

### Don't
- Cramp content
- set title and body at equal emphasis
- add a single harsh shadow as a substitute for spacing and hierarchy.

## Verification checklist

- [ ] The default state and all relevant alternate states are defined.
- [ ] Mouse, keyboard, and touch interactions have been considered where applicable.
- [ ] The interface communicates what happened and what the user can do next.
- [ ] Errors and reversible actions have a predictable recovery path.
- [ ] The implementation has been tested on mobile and desktop viewports.
- [ ] The recommendation has been adapted to context rather than applied blindly.
