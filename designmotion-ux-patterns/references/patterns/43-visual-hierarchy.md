## Key insights

- Hierarchy emerges from size, color, contrast, whitespace and weight working together.
- One accent color should identify the most important action
- a clear focal point matters more than maximizing visual decoration.

## Do / Don't

### Do
- Reserve accent for primary action
- combine scale with contrast and whitespace
- establish a clear first-read element.

### Don't
- Color every element differently
- rely on size alone
- give every item equal emphasis.
