## Key insights

- A 12-column grid divides cleanly into common ratios.
- Column proportions and gutters set density and tone
- responsive layouts should reduce columns at breakpoints.
- Intentional full-bleed exceptions work best against a consistent underlying grid.

## Do / Don't

### Do
- Align elements to shared edges
- adapt columns at breakpoints
- choose gutters to suit density and context.

### Don't
- Break the grid before establishing order
- use arbitrary widths when simple ratios fit
- keep desktop columns on narrow screens.
