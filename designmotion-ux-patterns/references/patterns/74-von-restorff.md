# 74. Von Restorff Effect

- **Source category:** `visual-design`
- **Official source:** [https://designmotionhq.com/patterns/von-restorff](https://designmotionhq.com/patterns/von-restorff)
- **Related skill:** `visual-design-systems`

> This document is an original technical summary of the linked public page, not a verbatim reproduction. Treat specific numbers and examples as source-informed heuristics and validate them against the product context, accessibility requirements, real data, and user testing.

## Key insights

- A single distinct element stands out only against a consistent baseline.
- Emphasize the primary CTA or target plan through a controlled combination of color, scale, elevation and glow, not color alone.
- Overuse erases the effect and can create inaccessible hierarchy.

## Do / Don't

### Do
- Keep most elements calm
- emphasize one important choice
- use multiple cues beyond color.

### Don't
- Highlight every card
- create several competing primary CTAs
- depend on color alone to distinguish the standout.

## Verification checklist

- [ ] The default state and all relevant alternate states are defined.
- [ ] Mouse, keyboard, and touch interactions have been considered where applicable.
- [ ] The interface communicates what happened and what the user can do next.
- [ ] Errors and reversible actions have a predictable recovery path.
- [ ] The implementation has been tested on mobile and desktop viewports.
- [ ] The recommendation has been adapted to context rather than applied blindly.
