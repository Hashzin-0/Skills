# 45. Zeigarnik Effect

## Key insights

- Visible unfinished work can encourage return when the goal is meaningful to the user.
- Progress indicators and incomplete checklists make open tasks salient, but the effect should support a real user goal rather than manufacture anxiety or busywork.

## Do / Don't

### Do
- Show useful progress toward a user-valued outcome
- make the next step clear
- let users finish or dismiss optional setup.

### Don't
- Invent fake progress
- manufacture unfinished chores
- use nagging progress UI for an outcome the user does not care about.
