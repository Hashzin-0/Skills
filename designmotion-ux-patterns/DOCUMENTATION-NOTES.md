# Documentation scope and provenance

This repository contains original English-language summaries of the 76 UX pattern pages listed in the catalogue. It does not reproduce the source pages word-for-word. Each pattern entry links to the relevant DesignMotionHQ page so readers and agents can consult the original text and any updates.

Use these summaries to orient audits and implementation decisions. For critical flows, verify source details, test with users, and validate accessibility and responsive behavior rather than treating a pattern as a universal rule.
